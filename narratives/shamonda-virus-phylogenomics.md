# [L: two European genetic backgrounds](https://nextstrain.org/fetch/raw.githubusercontent.com/BryanTegomoh/shamonda-virus-phylogenomics/main/auspice/shamonda_L.json?c=country&f_group=SHAV&treeZoom=selected)

**Read the colors:** each color represents a deposited country. Each tip is a
segment sequence, not necessarily an independent animal or complete genome.

European samples occupy two separated parts of the SHAV tree. The earlier
European group and EU2 both have strong L support: **SH-aLRT 100 / bootstrap 100**.
The two backgrounds are consistent with [published EU1/EU2 findings](https://pubmed.ncbi.nlm.nih.gov/42825336/).

**Epidemiological limit:** the tree does not establish a source country, entry
route or arrival date. A sampled relative is not necessarily an ancestor.

The horizontal axis counts inferred nucleotide changes. It is not a timeline.
Visualization: [Nextstrain/Auspice](https://nextstrain.org/).

# [M: support for EU2 is weaker](https://nextstrain.org/fetch/raw.githubusercontent.com/BryanTegomoh/shamonda-virus-phylogenomics/main/auspice/shamonda_M.json?c=country&f_group=SHAV&treeZoom=selected)

**Compare the same countries across segments.** European sequences do not form
one Europe-exclusive cluster in M either.

The earlier European group is strongly supported: **100 / 99**. EU2's M branch
has **74.7 / 88**, below the joint thresholds of SH-aLRT 80 and bootstrap 95.

**Surveillance implication:** the broad grouping is informative, but confidence
is not identical across the three segments. This difference alone does not
demonstrate reassortment, greater virulence or more efficient transmission.

The horizontal axis counts inferred nucleotide changes. It is not a timeline.
Visualization: [Nextstrain/Auspice](https://nextstrain.org/).

# [S: the human-case link remains unresolved](https://nextstrain.org/fetch/raw.githubusercontent.com/BryanTegomoh/shamonda-virus-phylogenomics/main/auspice/shamonda_S.json?c=country&f_group=SHAV&treeZoom=selected)

**This view covers the N coding region**, not the entire S segment or its
overlapping NSs gene.

EU2 is strongly supported: **99.5 / 100**. The earlier European group has
**87.8 / 91**, below the joint strong-support thresholds.

**The human case cannot be assigned to either group.** No explicitly
human-labelled sequence was identified in the 22 October snapshot. Fifty focal
records lack host metadata, so this does not prove global absence of a deposited
human sequence.
